Arquitectura Electronica

Puente entre IRC5 (24V) y SG90 (5V PWM)

IRC5 → Arduino

DO_04 → 2.2k → PC817 #1 → D2
DO_06 → 2.2k → PC817 #2 → D4
Pull-down 10k en D2 y D4

Arduino → IRC5

D5 → Rele #1 → DI_04 (gripOK)
D6 → Rele #2 → DI_05 (HOME)
D7 → Rele #3 → DI_06 (START)

Potencia

LM2596: 24V → 5V
D9 → PWM → SG90
1000uF + 100nF filtro

Aislamiento galvanico PC817 Contactos secos (reles) Antirrebote 30ms
