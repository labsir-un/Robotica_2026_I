## Introducción

Este repositorio reúne en un único espacio el material académico y los proyectos desarrollados durante el **Curso de Robótica 2026-I**. Su propósito es facilitar la consulta, navegación y preservación de la documentación generada durante el semestre, evitando que el contenido quede disperso entre múltiples repositorios independientes.

El repositorio consolida dos grandes componentes del curso:

- **Material del profesor:** seis guías docentes relacionadas con Ubuntu 24.04 LTS, ROS 2 Jazzy, Turtlesim, arquitectura de ROS 2, TurtleBot3 y PhantomX Pincher X100.
- **Proyectos de estudiantes:** catorce repositorios correspondientes a los diferentes equipos del curso, conservando la organización de sus laboratorios y proyectos finales.

En total se integran **20 repositorios** dentro de una única estructura de navegación.

---

## Objetivo

Centralizar la documentación del curso de Robótica 2026-I en un único repositorio, manteniendo una separación clara entre el material docente y el trabajo de los estudiantes, y conservando dentro de cada carpeta la estructura documental necesaria para consultar los README, imágenes, resultados y demás recursos asociados.

> **Importante:** los repositorios originales no fueron modificados. Este repositorio corresponde a una consolidación independiente de su contenido documental.

# 4. Criterio de consolidación

Para construir este repositorio se siguieron los siguientes criterios:

- Se conservaron los archivos **README y Markdown** disponibles en cada repositorio fuente.
- Se conservaron los **recursos locales utilizados por la documentación**, incluyendo imágenes, diagramas, resultados, PDFs y archivos asociados cuando eran necesarios para interpretar correctamente los README.
- Las imágenes que originalmente apuntaban mediante URL absoluta al propio repositorio fuente se adaptaron, cuando fue posible, para funcionar mediante rutas internas en este repositorio consolidado.
- Se mantuvieron los **enlaces externos** que forman parte de las instrucciones originales, por ejemplo dependencias, documentación externa o repositorios que el estudiante debe clonar durante una práctica.
- No se modificó el contenido técnico original de los trabajos de los estudiantes ni de las guías docentes.
- No se copiaron indiscriminadamente archivos pesados que no eran necesarios para la documentación, como determinados videos, archivos comprimidos, workspaces completos o proyectos de simulación sin referencias desde los README.

# 5. Inventario y referencias
